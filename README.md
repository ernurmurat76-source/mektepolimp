# MektepOlimpiada

Егемқұл Тасанбаев атындағы ЖББМ-нің 5–11-сынып оқушыларына арналған мектепішілік онлайн пән олимпиадасы және 11-сыныпқа арналған ҰБТ дайындық сынағы.

## Іске қосу

1. Компьютерге Node.js 18 немесе одан жаңа нұсқасын орнатыңыз.
2. Осы папка ішінде терминалды ашыңыз.
3. `npm start` командасын орындаңыз.
4. Браузерден `http://localhost:3000` мекенжайын ашыңыз.

## Әкімші кабинеті

- Логин: `admin`
- Алғашқы құпиясөз: `Mektep2026!`

Сайтты интернетке шығармас бұрын құпиясөзді `server.js` файлында немесе орта айнымалысы арқылы міндетті түрде өзгерту қажет.

## Қазір жұмыс істейтін мүмкіндіктер

- 5–11-сынып пен 12 пән бойынша оқушыны тіркеу;
- бірегей қатысу кодын автоматты жасау;
- код арқылы тестке кіру;
- сервер уақытымен есептелетін таймер;
- тестті бір рет тапсыру;
- автоматты бағалау;
- әкімшіге қатысушылар, сұрақтар және нәтижелер статистикасы;
- сұрақ қосу/өшіру және тест ұзақтығын өзгерту;
- PostgreSQL-де тұрақты сақтау;
- 11-сыныпқа арналған бөлек ҰБТ бағыты: 120 тапсырма, 240 минут, 140 балл;
- ҰБТ сұрақтарын бөлек Word/Excel қорына импорттау;
- ҰБТ қатысушыларының бөлек рейтингі және Word есебі.

## AI арқылы сұрақ генерациялау

Gemini API кілтін браузерге немесе кодтың ішіне жазбаңыз. PowerShell терезесінде серверді мынадай түрде іске қосыңыз:

```powershell
$env:GEMINI_API_KEY="өзіңіздің_API_кілтіңіз"
npm start
```

Әкімші панеліндегі **AI генерация** батырмасынан сынып, пән, сұрақ саны және тілді таңдаңыз. Модельді `GEMINI_MODEL` айнымалысымен өзгертуге болады. AI жасаған тапсырмалар қате жіберуі мүмкін, сондықтан мұғалім жариялар алдында сұрақты, дұрыс жауапты және оқу бағдарламасына сәйкестігін тексеруі тиіс.

## ҰБТ сұрақтарын импорттау

Әкімші панелінен **ҰБТ басқару → Word / Excel сұрақ қосу** таңдаңыз. Бірінші жолдағы бағандар:

`Пән | Сұрақ | A | B | C | D | E | Дұрыс жауап | Ұпай`

`E` бағаны бос болуы мүмкін. Міндетті пәндерге 1 ұпай қойылады. Әр бейіндік пән қорында кемінде 30 бір ұпайлық және 10 екі ұпайлық тапсырма болуы керек. Панель қордың жеткіліктілігін автоматты көрсетеді.

## Railway-ге пилот ретінде жариялау

1. Жоба файлдарын GitHub репозиторийіне жүктеңіз (ZIP файлын емес, ішіндегі файлдарды).
2. Railway-де **New Project → Deploy from GitHub repo** таңдаңыз.
3. Variables бөліміне `ADMIN_PASSWORD`, `SESSION_SECRET`, `GEMINI_API_KEY` және PostgreSQL жасағанда берілетін `DATABASE_URL` мәндерін қосыңыз. Құпия мәндерді GitHub-қа жүктемеңіз.
4. Settings → Networking → **Generate Domain** басыңыз.
5. Нәтижелер PostgreSQL-де сақталады. Volume тек қосымша файлдар үшін қажет; негізгі нәтиже қоры үшін міндетті емес.

Жарияланған нұсқада әкімші паролі `ADMIN_PASSWORD` айнымалысынан оқылады. Ол берілмесе, жергілікті демодағы бастапқы пароль қолданылады.
