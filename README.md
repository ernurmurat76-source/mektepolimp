# MektepOlimpiada

Егемқұл Тасанбаев атындағы ЖББМ-нің 5–11-сынып оқушыларына арналған мектепішілік онлайн пән олимпиадасының MVP жүйесі.

## Іске қосу

1. Компьютерге Node.js 18 немесе одан жаңа нұсқасын орнатыңыз.
2. Осы папка ішінде терминалды ашыңыз.
3. `npm start` командасын орындаңыз.
4. Браузерден `http://localhost:3000` мекенжайын ашыңыз.

## Әкімші кабинеті

- Логин: `admin`
- Алғашқы құпиясөз: `Mektep2026!`

Сайтты интернетке шығармас бұрын құпиясөзді `server.js` файлында немесе орта айнымалысы арқылы міндетті түрде өзгерту қажет.

## Қазір жұмыс істейтін мүмкіндіктер

- 5–11-сынып пен 12 пән бойынша оқушыны тіркеу;
- бірегей қатысу кодын автоматты жасау;
- код арқылы тестке кіру;
- сервер уақытымен есептелетін таймер;
- тестті бір рет тапсыру;
- автоматты бағалау;
- әкімшіге қатысушылар, сұрақтар және нәтижелер статистикасы;
- сұрақ қосу/өшіру және тест ұзақтығын өзгерту;
- мәліметтерді `data/db.json` ішінде сақтау.

## AI арқылы сұрақ генерациялау

OpenAI API кілтін браузерге немесе кодтың ішіне жазбаңыз. PowerShell терезесінде серверді мынадай түрде іске қосыңыз:

```powershell
$env:OPENAI_API_KEY="өзіңіздің_API_кілтіңіз"
npm start
```

Әкімші панеліндегі **AI генерация** батырмасынан сынып, пән, сұрақ саны және тілді таңдаңыз. Әдепкі модель `gpt-6-astra`; қажет болса серверді қосар алдында `$env:OPENAI_MODEL="модель_атауы"` деп өзгертуге болады. AI жасаған тапсырмалар қате жіберуі мүмкін, сондықтан мұғалім жариялар алдында сұрақты, дұрыс жауапты және оқу бағдарламасына сәйкестігін тексеруі тиіс.

## Өндірістік серверге дейін қосылатындар

- PostgreSQL дерекқоры;
- әкімші құпиясөзін хэштеу және өзгерту беті;
- Excel импорт/экспорт;
- дипломды PDF жасау;
- пән мұғалімдерінің жеке кабинеті;
- жауаптарды кезең-кезеңімен автоматты сақтау;
- резервтік көшіру, HTTPS және журнал жүргізу.

## Railway-ге пилот ретінде жариялау

1. Жоба файлдарын GitHub репозиторийіне жүктеңіз (ZIP файлын емес, ішіндегі файлдарды).
2. Railway-де **New Project → Deploy from GitHub repo** таңдаңыз.
3. Variables бөліміне `ADMIN_PASSWORD` және `OPENAI_API_KEY` мәндерін қосыңыз. Құпия мәндерді GitHub-қа жүктемеңіз.
4. Settings → Networking → **Generate Domain** басыңыз.
5. Нәтижелерді сақтау үшін Volume жасап, оны `/app/data` жолына тіркеңіз.

Жарияланған нұсқада әкімші паролі `ADMIN_PASSWORD` айнымалысынан оқылады. Ол берілмесе, жергілікті демодағы бастапқы пароль қолданылады.
